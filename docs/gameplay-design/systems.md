# 系统设计

## 流派系统

流派是 Puritato 的构筑边界。武器、魔法、道具、角色、怪物和剧情都可以归属到一个或多个流派。

当前已定义流派包括：

- 变形学派：土豆、山药、生姜、大麦等植物，特点是学习能力强、全面发展、没有明显短板；在游戏中提供通用能力。
- 战斗学派：竹子、芹菜、西兰花、莴苣等，擅长近身格斗；提供锻造、近战与防御提升。
- 感染学派：各种蘑菇，擅长感染、毒素和禁忌法术。
- 爆破学派：常见水果，擅长炸弹、火焰和陷阱。
- 炼药学派：花朵，擅长治疗、炼药和正面 buff。
- 刺杀学派：针叶松、板栗、槟榔、捕蝇草、大蒜等，擅长暴击、处决、隐蔽、毒、镖和匕首。
- 占卜学派：烟草、薄荷、罂粟等，使用幻术和占卜术。
- 大气学派：海洋植物，控制天气，制造有利条件。
- 自然科学派：豆类学者，提升其他学派能力上限。

### 流派随机池规则

每个角色拥有固定主流派。角色主流派会影响开局和后续奖励池，例如免费武器、商店首位保底、随机道具首位等。

后续物品池由角色主流派与玩家已获得物品的流派共同决定。角色主流派提供稳定的构筑起点，已获得的武器、魔法、道具等能力则会持续影响后续随机池的可选范围。

变形学派不计入非变形学派数量限制，但如果角色主流派是变形学派，仍然正常参与主流派保底。

常规情况下，玩家拥有的武器、道具、技能只能来自最多 3 个非变形学派。变形学派不参与该数量限制。

当玩家已经拥有至少 3 个非变形学派能力时，后续随机池只从这 3 个学派与变形学派中抽取。

当玩家拥有的非变形学派少于 3 个时，随机池可以抽出新学派物品。

部分武器、道具、魔法可能同时属于多个学派。多学派物品只有在玩家当前构筑已经覆盖该物品所有学派时才会出现。多学派物品仍然只有一个主学派。

主学派是物品的兜底元数据，不一定在当前核心规则中直接生效。它主要用于未来可能出现的按学派归类、重随、转化、升品等效果，例如某个道具将角色物品随机转化为品质更高的同一学派物品。当前物品 ID 结构中也天然包含主学派 ID 片段。

### 获取数量上限

武器、魔法、道具都拥有“获取数量上限”字段，用于控制它们能在一局游戏中出现多少次。

- 获取数量上限为 0 时，表示该物品可以无限次出现。
- 获取数量上限为正数时，表示该物品在达到对应获取次数后不再进入随机池。
- 默认情况下，武器、魔法、道具的获取数量上限均为 0。

重复获取本身是有意义的：重复武器和重复魔法可以服务于融合机制，被动道具则支持叠加。是否允许某个物品无限重复或只出现有限次，应由具体物品配置决定。

### 品质

品质用于控制物品稀有度和价格。当前品质包括普通、稀有、传说。

品质不直接决定强化次数、融合上限、词条承载上限或其他基础规则。这些限制由具体物品、强化、融合或特殊效果配置决定。

## 战斗系统

战斗整体接近 Brotato。玩家触发战斗后进入战斗地图中央，怪物从地图周围逐渐生成并向玩家攻击。玩家通过武器、魔法、道具等自动或半自动效果击败怪物。

### 操作模型

游戏默认操作尽量简化，核心输入是移动和少量主动技能。

- 默认情况下，玩家没有主动闪避或冲刺。
- 闪避、冲刺等额外动作能力可以由特定角色、道具或魔法提供。
- 设计时需要兼顾手柄与手机：手柄左摇杆负责移动，右侧按钮数量有限；手机右侧操作区也应控制在少量技能以内。
- 局内默认最大魔法技能栏位数为 3，第 4 个栏位作为预留扩展，主要通过道具或奇遇解锁；当前阶段暂不细化。
- 武器默认自动瞄准、自动攻击，不要求玩家手动瞄准。
- 武器与技能的目标优先级可以配置，例如最近目标、血量最低、Boss 优先、精英优先等。

### 背包与装备

玩家获得的武器和魔法会进入背包栏。背包用于保存当前局内已经获得、但不一定正在装备的武器与魔法。道具不进入背包。

- 背包容量默认无限。
- 当对应装备栏位有空位时，新获得的武器或魔法会自动装备。
- 当对应装备栏位已满时，新获得的武器或魔法只进入背包，不强制替换当前装备。
- 战斗外，玩家可以在地图节点、奖励节点、商店节点等非战斗状态中，在背包与装备栏之间调配武器和魔法。
- 进入战斗后，当前装备锁定，直到战斗结束。
- 多余武器和魔法不会失去价值，可用于融合、强化等局外节点活动。
- 战斗中装备栏决定实际参与战斗的武器与魔法；背包内容主要作为战斗外调整和成长资源。

### 融合与强化

融合和强化是武器、魔法的两类主要成长服务。

融合偏向横向玩法扩展。武器融合、魔法融合的核心规则是被动或词条转移：选择一个目标武器/魔法与一个材料武器/魔法，将材料的特性、被动、词条转移到目标上，从而组合不同物品的玩法特征。

默认情况下，被融合的一方作为材料会被消耗。若材料物品上已经投入强化石或等价强化资源，则融合时返还这些强化石。后续可以设计特殊效果豁免材料消耗，但这属于特例规则。

融合允许跨学派。具体某个武器或魔法能否作为目标或材料参与融合，可能受其技能、被动效果、词条或特殊条件限制。这些限制在设计具体物品时体现。

默认情况下，每个武器或魔法最多承载 2 个其他物品转移来的被动或词条。该承载上限可以通过部分道具或特殊效果扩展。

强化偏向纵向属性提升，概念上类似“强化石”。强化通常提供基础属性或特性的增益，例如：

- 武器伤害提高。
- 攻击速度提高。
- 武器技能充能速度提高。
- 魔法冷却减少。
- 魔法蓝耗减少。
- 魔法效果范围或持续时间提高。

默认情况下，每个武器或魔法拥有 2 个强化槽。强化槽数量可以通过部分道具或特殊效果扩展。

具体融合限制、可转移词条类型、强化池和强化数值，均属于后续可配置内容。

一场战斗分为两个阶段：

- 小怪阶段：怪物按一定配置和频率生成，玩家需要存活一定时间。
- Boss 阶段：关卡 Boss 出现，玩家必须击败 Boss 才能取得战斗胜利。

### 战斗节奏

Boss 出现时间随章节和层数变化。玩法层面的核心规则是：越靠后的层，战斗的小怪阶段越长，玩家需要承受更久的构筑压力后再进入 Boss 阶段。

具体数值应作为可配置项处理，并允许随难度、模式、章节主题和后续数值调整动态变化。Demo 版本先采用以下默认节奏基准：

| 层 | 小怪阶段时长 | Boss 出现时间 |
|-|-:|-:|
| 第 1 层 | 45 秒 | 45 秒 |
| 第 2 层 | 50 秒 | 50 秒 |
| 第 3 层 | 60 秒 | 60 秒 |
| 第 4 层 | 70 秒 | 70 秒 |
| 第 5 层 | 80 秒 | 80 秒 |
| 第 6 层 | 90 秒 | 90 秒 |

Boss 出现后是否继续刷小怪、刷怪强度如何变化、是否加入精英怪、召唤物或环境危险，均按 Boss 配置决定，不设全局硬规则。

### 韧性与控制

韧性系统用于承载破韧、处决、眩晕、打断等战斗控制机制。

- 敌人可以拥有韧性值。
- 攻击可以造成韧性伤害。
- 当敌人韧性归零时，进入破韧状态。
- 破韧状态下可以触发处决伤害，或更容易受到控制效果影响。
- 眩晕会让敌人停止移动和攻击。
- 打断会取消敌人当前动作。

更多控制效果不在基础规则里一次性写死，后续通过 buff 系统细化。

### Buff 系统

Buff 系统用于承载增益、减益、异常状态、控制效果和部分触发规则。Buff 不设单一默认叠加模型，具体叠加方式、持续时间处理和结算规则由每个 buff 自身定义。

Buff 的作用对象可以包括：

- 角色自身。
- 武器。
- 魔法。
- 怪物。
- 区域或光环。
- 全局战斗环境。

Buff 可以通过分类或标签描述其性质，例如常规负面、常规增益、异常状态、控制、光环、Boss 专属 buff 等。驱散、转化、免疫、增幅等效果应根据 buff 标签判断是否能够影响目标 buff。

Buff 的结算频率由 buff 自己配置。持续伤害或持续治疗等效果可以采用每秒一次作为常见取值，但这不是硬规则。

典型模式包括：

- 层数叠加，每层独立计时：适合强化光环等效果。
- 只刷新时间，不叠层：适合眩晕等控制效果。
- 层数叠加，持续时间刷新：适合中毒等异常状态。

每个 buff 条目至少应明确：作用对象、分类/标签、是否可叠加、最大层数、持续时间、重复获得时如何处理、是否独立计时、结算频率、影响属性或行为、可被哪些标签规则影响。

### 受击规则

玩家受击后拥有短暂无敌帧，但不产生受击硬直，避免操作被频繁打断。

除通用受击无敌帧外，针对单个伤害源还存在独立无敌帧，并且持续时间更长。例如同一个怪物的碰撞、同一颗子弹或同一个持续伤害源，不能在独立无敌帧内反复造成伤害。

### 法力、能量与冷却

法力是魔法释放的常规资源。魔法主动释放时需要消耗法力，法力不足时不能释放。法力可以通过角色属性、道具、魔法、buff 等方式恢复或提高上限。

能量是更稀缺的杀招资源，用于特定强力魔法、角色技能或特殊效果。能量点上限获取难度高，且不随战斗进行自然恢复。能量的获取、消耗和上限提升应作为重要构筑点处理。

冷却是释放频率限制。即使法力或能量足够，也需要等待对应魔法或技能冷却结束后才能释放。

### 伤害公式方向

伤害公式先采用易扩展的乘区框架，具体数值细节后续配置。

- 武器、魔法拥有基础伤害。
- 近战武器主要受近战攻击加成。
- 远程武器主要受远程攻击加成。
- 魔法伤害由魔法自身字段与相关魔法属性、buff、强化决定。
- 攻击倍率作为最终乘区之一。
- 暴击在命中后单独乘以暴击倍率。
- 处决伤害只在破韧或其他处决条件满足时触发。

“精准”暂不作为 Demo 核心属性，当前文档先移除该字段。后续如果需要命中、弱点、暴击稳定性等机制，可以重新引入。

### 战斗奖励

战斗胜利后会触发战斗奖励。战斗奖励按层类型变化，不是全局固定掉落。它的表现接近地图奖励节点。

默认情况下，战斗奖励中的武器三选一、魔法三选一、道具三选一都需要主流派保底：至少一个选项来自玩家角色主流派。具体奖励配置可以覆盖或调整该保底规则。

Demo 默认战斗奖励为金币 + 道具三选一。金币数量参考金币节点并随累计层数增加；道具三选一次数参考地图随机道具节点随章节增加；战斗节点的道具候选默认是传说品质。

| 第 2 层 | 第一章 | 225 金币 + 1 次传说道具三选一 |
| 第 3 层 | 第一章 | 300 金币 + 1 次传说道具三选一 |

## 武器系统

玩家可以同时持有多把武器。战斗表现上不要求角色本体长出真实手臂：土豆角色可以使用类似 Brotato 的“圆形悬浮手”作为武器握持点。每个武器装备栏对应一个围绕角色分布的悬浮握持点，默认数量为 4；通常一把武器占用一个武器栏位。

该表现约定只影响战斗动画与美术拆分，不改变角色在概念图、头像、剧情插画中的造型。概念图中的土豆少侠仍然可以有手；但战斗内角色本体应优先保持简洁土豆轮廓，武器攻击动作由“悬浮圆形手 + 武器 + 武器特效”承担，不要求角色本体播放攻击动作或专用攻击帧。

未装备武器的握持点默认隐藏；若后续需要“徒手”攻击，应作为一个可配置的虚拟武器或握持点表现处理，而不是要求角色本体出拳。

通常情况下，武器会在攻击范围内存在敌人时自动瞄准并自动攻击。每把武器可以配置目标优先级。

武器基础信息：

- 名称。
- 品质：普通、稀有、传说；影响稀有度和价格。
- 简介。
- ID：由 `2 + 学派ID + 学派武器ID` 拼接组成。
- 主学派：由 ID 中的学派 ID 片段天然表达，用作兜底元数据和未来扩展。
- 获取数量上限：0 表示可无限出现，正数表示本局最多可获取次数。

武器战斗属性：

- 类型：近战或远程。
- 伤害。
- 攻速。
- 被动效果：武器专属被动，可通过武器融合传递到其他武器。
- 强化效果：通常来自武器商店或武器大师。
- 武器技能：每隔一定时间、累计杀敌数或累计伤害等条件充能完毕后，在有目标时自动释放。
- 学派：影响武器出现时机。
- 目标优先级：决定自动瞄准时优先攻击哪类目标。
- 范围。
- 暴击率，默认 0%。
- 暴击倍率，默认 200%。
- 击退。

近战武器额外属性：

- 韧性伤害：命中后削减敌人韧性，默认 4。
- 动作模组：挥砍、穿刺、旋转等，默认挥砍。

远程武器额外属性：

- 穿透次数，默认 0。
- 穿透伤害递减，默认 25%。

## 魔法系统

魔法都会占用魔法技能栏位，即使是主要提供被动、光环或自动触发效果的魔法。局内默认最大魔法技能栏位数为 3，第 4 个栏位作为预留扩展，主要通过道具或奇遇解锁；当前阶段暂不细化。

角色如果拥有主动技能，也会占据一个魔法技能栏位，并在逻辑上视为魔法能力，可以参与魔法强化或魔法融合。

源文档目前给出魔法商店、魔法大师和一个魔法样例。根据这些内容，魔法至少包含：

- 学派。
- 品质。
- 魔法 ID。
- 主学派：由 ID 中的学派 ID 片段天然表达，用作兜底元数据和未来扩展。
- 获取数量上限：0 表示可无限出现，正数表示本局最多可获取次数。
- 耗蓝量。
- 冷却时间。
- 能量消耗。
- 被动效果。
- 法术效果。

### 魔法字段模板

魔法条目建议使用以下字段模板：

| 类别 | 字段 |
|-|-|
| 基础信息 | 名称、ID、学派、主学派、品质、简介、获取数量上限 |
| 装备信息 | 是否占用魔法技能栏、栏位类型 |
| 释放信息 | 主动/自动、耗蓝量、能量消耗、冷却时间、释放条件 |
| 效果信息 | 法术效果、被动效果、buff 列表、目标规则、目标优先级 |
| 成长信息 | 可强化属性、可融合词条、融合限制 |
| 表现信息 | 动画、音效、特效占位 |

默认规则是：所有魔法都占用魔法技能栏。字段中的“是否占用魔法技能栏”主要用于显式记录和未来特殊规则检查，不代表当前存在不占栏魔法。

魔法也可以通过被动效果实现自动释放，例如“全面发展”每隔 15 秒自动免费释放一次。默认规则仍是主动释放，自动释放属于具体魔法或强化带来的特殊效果。

拥有自动释放效果的魔法仍然可以主动释放。自动释放是额外触发，不消耗主动释放机会。自动释放是否消耗法力或能量，由具体魔法、强化或 buff 效果写明；如果效果注明“免费释放”，则不消耗对应资源。

Buff 的叠加层数、持续时间刷新、重复触发、上限和结算顺序等细节在 buff 系统中描述，由具体 buff 自身声明。

当同一帧有多个自动效果触发时，逻辑上使用固定顺序结算，保证结果可预测。默认优先级为：角色被动 > 道具被动 > 武器技能 > 魔法自动释放 > buff 触发。同类效果按装备栏顺序或获得顺序结算。

表现层面应尽量让同一帧触发的效果在体感上接近“同时触发”。具体事件队列、表现同步和延迟策略留到后续架构设计中细化。

## 道具系统

源文档目前给出道具商店和一个道具样例。道具是构筑中的被动成长来源，受流派随机池限制。

道具都是被动效果，获得后立即生效，不进入背包，也不占用装备栏位。被动道具支持重复获取与叠加。每个道具通过“获取数量上限”控制是否可以无限叠加，或只允许在一局中出现有限次。

所有道具默认可以叠加。当道具达到自身获取数量上限后，不再进入随机池。

### 道具字段模板

道具条目建议使用以下字段模板：

| 类别 | 字段 |
|-|-|
| 基础信息 | 名称、ID、学派、主学派、品质、简介、获取数量上限 |
| 生效方式 | 获得后立即生效、是否可叠加、叠加方式 |
| 效果信息 | 被动效果、buff 列表、触发条件、影响对象 |
| 构筑信息 | 是否进入随机池、是否可被奇遇/事件转换 |
| 表现信息 | 图标、获得提示、特效占位 |

## 怪物系统

怪物从地图周围生成，向玩家移动并造成接触伤害。怪物属性会随小关推进成长。

普通怪物默认只作为战斗压力，不承担固定掉落。战斗中仍然可能出现金币、物品或其他资源掉落，但这应由具体怪物类别、道具效果、buff、关卡配置或特殊规则决定。

### 怪物字段模板

怪物条目建议使用以下字段模板：

| 类别 | 字段 |
|-|-|
| 基础信息 | 名称、ID、学派、类型、简介 |
| 属性 | 生命、生命成长、攻击力、攻击成长、速度、击退抗性、韧性 |
| 行为 | 移动方式、攻击方式、目标选择、碰撞伤害 |
| 生成 | 出现章节/层数、生成权重、波次配置、是否精英/Boss |
| 掉落/奖励 | 默认无固定掉落；特殊金币、物品或资源掉落规则 |
| 表现信息 | 动画、音效、特效占位 |

## 经济与成长服务

金币主要通过金币节点和战斗奖励获得，并用于购买商店内容、刷新、强化与融合服务。

当前已定义价格趋势：

- “层”按跨章节累计的小关进度计算，不会在进入新章节时重置。
- 武器商店、魔法商店的物品和服务每过一层价格提高 10 金币。
- 锻造大师、魔法大师的强化服务每层提高 5 金币。
- 土豆少侠被动会让每个商店购买的第一个物品半价。
