## 当前设计状态

Puritato 是一款类 Vampire Survivors / Brotato 的自动攻击生存 roguelike。玩家扮演“土豆少侠”，在一局游戏中沿章节地图推进，通过奖励节点和战斗节点构筑武器、魔法、道具与流派组合，最终清理污染源。

当前源文档已经比较明确的部分：

- 游戏核心参考：吸血鬼幸存者、Brotato、怪物火车、邪恶铭刻、以撒的结合、哈迪斯、神界原罪。
- 单局主线：进入污染区域，沿地图路线获得奖励，完成战斗，逐步深入污染更深处。
- 战斗结构：小怪存活阶段 + Boss 击杀阶段。
- 地图结构：章节由多个小关区域组成，路线节点提供商店、金币、道具、奇遇等成长选择。
- Demo 终点：通关第二章后视为游戏胜利，第三章作为后续扩展内容。
- 构筑限制：常规情况下非变形学派能力最多来自 3 个学派，变形学派不参与计数。
- 首个内容切片：变形学派、土豆少侠、薯条、全面发展、土豆强化、发芽土豆。
