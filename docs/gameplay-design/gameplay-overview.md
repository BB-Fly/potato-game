# 玩法总览

## 游戏定位

Puritato 是一款自动攻击生存 roguelike。核心体验是：玩家在地图路径上做构筑选择，在战斗中依靠自动触发的武器、魔法和道具效果抵抗怪物潮，并在 Boss 阶段完成击杀。

单局体验强调三件事：

- 路线选择：在章节地图中选择奖励路线，决定本局成长方向。
- 构筑管理：围绕角色、武器、魔法、道具和学派形成组合。
- 战斗验证：在小怪压力和 Boss 机制下检验构筑强度。

## 玩家叙事目标

玩家扮演土豆少侠，展开一次清理污染的旅程。过程中主角会得到各学派帮助，赢得战斗、夺回区域、击败污染源头。

失败时，主角会被刺杀学派的线人带回，准备下一次行动。成功时，主角会在夺回区域种下希望种子，并谋划下一次行动。

## 单局流程

1. 玩家点击开始游戏。
2. 选择角色和难度。
3. 进入第一章地图。
4. 在地图节点中获得武器、道具、金币、商店服务或奇遇。
5. 进入战斗节点，完成小怪阶段和 Boss 阶段。
6. 战斗胜利后领取奖励，进入下一小关或下一章。
7. Demo 版本以通关第二章作为胜利终点；第三章属于后续扩展内容。

## 地图结构

地图参考怪物火车式路线推进，但使用 Puritato 自己的植物污染主题美术语言。章节地图由多个小关区域组成，每个小关区域约占一个屏幕，并按自下而上的方向排列。玩家从屏幕底部入口进入当前区域，在左右两条路线中选择一条；每条路线沿途两侧摆放不同奖励节点，路线末端汇总到同一个战斗节点。

战斗胜利后，地图视角上移到下一小关区域。已经解锁或经过的区域可以回看：鼠标滚轮用于在上一关/下一关地图间滚动；手柄右摇杆上下推动用于连续滚动，方向键上下用于按区域吸附切换。回看只用于查看信息，不撤销已经做出的路线选择。

地图节点分为两类：

- 奖励节点：商店、金币、奇遇、随机道具、免费武器、锻造大师、魔法大师等。
- 战斗节点：必须完成战斗并获得战斗奖励，才能继续推进。

战斗奖励本质上也是一种奖励节点，但触发条件是完成战斗。Demo 默认战斗奖励为金币 + 道具三选一。金币数量和道具三选一次数随层数增加；战斗节点的道具候选默认是传说品质。具体组合、数量和权重仍可随层数、章节、难度和模式调整。

### 层级定义

“层”指跨章节累计的小关进度，不会在进入新章节时重置。

例如：第一章第一小关为第 1 层，第一章第二小关为第 2 层，第一章第三小关为第 3 层；第二章第一小关继续作为第 4 层。所有“每过一层价格提高”的规则都按该累计层数计算。

## 第一章地图

第一章由三个小关区域组成。

第一小关：

- 玩家进入第一章第一片区域。
- 从两条初始路线中选择一条；每条路线至少提供起始武器保障，并在路线两侧摆放不同奖励节点。
- 两条路线最终汇总到同一个第一小关战斗节点。
- 胜利后领取战斗奖励，进入第二小关区域。

第二小关：

- 玩家从左右两条路线中选择一条。
- 一条路线为：武器商店 + 道具商店 + 金币。
- 另一条路线为：武器商店 + 魔法商店 + 金币。
- 两个武器商店必定是不同流派主题。
- 完成路线奖励后，两条路线汇总到同一个战斗节点。
- 胜利后领取战斗奖励，进入第三小关区域。

第三小关：

- 玩家再次进行二选一路线选择。
- 一条路线包含：武器或魔法商店 + 道具商店 + 随机道具。
- 另一条路线包含：武器或魔法商店 + 道具商店 + 奇遇。
- 两边必定一个是武器商店，一个是魔法商店。
- 完成路线奖励后，两条路线汇总到同一个战斗节点。
- 胜利后领取战斗奖励，进入第二章地图。

## 第二章地图

第二章结构接近第一章，但路线节点组合不同。

第一小关：

- 路线 A：金币 + 奇遇 + 道具/武器/魔法商店。
- 路线 B：奇遇 + 道具 + 道具/武器/魔法商店。
- 两边商店类型一定不同。
- 完成路线奖励后，两条路线汇总到同一个战斗节点，胜利后领取战斗奖励。

第二小关：

- 两边路线都由商店/事件/大师节点组成。
- 每条路线大致为：武器商店或魔法商店 + 奇遇或道具 + 武器大师或魔法大师。
- 两边必定不存在相同节点。
- 完成路线奖励后，两条路线汇总到同一个战斗节点，胜利后领取战斗奖励。

第三小关：

- 路线组合回到类似第二章第一小关。
- 路线 A：金币 + 奇遇 + 道具/武器/魔法商店。
- 路线 B：奇遇 + 道具 + 道具/武器/魔法商店。
- 两边商店类型一定不同。
- 完成路线奖励后，两条路线汇总到同一个战斗节点；完成第三小关战斗并领取战斗奖励后，Demo 版本判定为通关胜利。

## Demo 终点与后续章节

Demo 版本以通关第二章后游戏胜利作为完整闭环。第三章暂不纳入 Demo 范围，作为后续扩展内容规划。

## 节点设计

### 免费武器节点

只出现在第一章第一小关前，为玩家提供起始武器资源。该节点不是新手保护；如果后续需要新手保护，应作为独立系统设计。

- 提供随机武器三选一。
- 第一把武器必定与玩家主流派相同。
- 玩家主流派由当前角色固定决定。
- 后两把武器来自所有流派随机池。

### 随机道具节点

提供随机道具三选一。

- 第一章中提供 1 次选择。
- 第二章中连续提供 2 次选择。
- 第三章中连续提供 3 次选择。
- 第一个选项必定来自玩家主流派。
- 其余选项来自其他随机流派。

### 武器商店节点

默认售卖 3 个武器。

- 第一个武器来自玩家主流派。
- 其余武器随机。
- 普通品质价格：65-80 金币。
- 稀有品质价格：95-100 金币。
- 传说品质价格：120-135 金币。
- 服务：武器融合、武器强化、刷新，默认各 75 金币，且每项只能购买一次。
- 刷新会替换全部武器售卖栏位，并补齐 3 把符合流派池与获取数量上限的随机武器；同一次售卖候选中默认避免重复展示同一武器。
- 刷新出的新武器不再固定来自玩家主流派。
- 所有物品和服务每过一层价格提高 10 金币。

### 魔法商店节点

默认售卖 3 个魔法。

- 第一个魔法来自玩家主流派。
- 其余魔法随机。
- 普通品质价格：40-55 金币。
- 稀有品质价格：65-75 金币。
- 传说品质价格：100-120 金币。
- 服务：魔法强化、魔法融合、刷新，默认各 75 金币，且每项只能购买一次。
- 刷新规则与武器商店一致，候选魔法同样受流派池与获取数量上限约束。
- 所有物品和服务每过一层价格提高 10 金币。

### 道具商店

默认售卖 5 个道具。

- 一个来自玩家主流派。
- 其余来自随机流派。
- 普通品质价格：75-90 金币。
- 稀有品质价格：100-115 金币。
- 传说品质价格：130-150 金币。
- 提供一次可购买的刷新服务，刷新全部道具栏位；候选道具受流派池与获取数量上限约束。

### 金币节点

提供固定数量金币。

- 第 1 层：150 金币。
- 第 2 层：225 金币。
- 第 3 层：300 金币。

金币奖励默认按每层 +75 金币继续增长，用于战斗奖励等需要跨章节累计的场景。

### 奇遇节点

触发一个随机事件，由玩家做出选择。

奇遇不需要强行归类，具体效果由单个奇遇事件设计决定。可能出现的方向包括：风险收益选择、流派权重干预、物品转换、突破限制、背包或装备服务、免费融合或强化、资源奖励、商店折扣、门派 NPC 剧情、污染事件、希望种子相关事件等。

### 锻造大师节点

偏向武器成长。

- 以 40 金币一个的价格售卖 3 个武器强化。
- 免费提供一个随机武器。
- 免费提供一次武器融合。
- 武器强化售卖价格每层提高 5 金币。

### 魔法大师节点

偏向魔法成长。

- 以 40 金币一个的价格售卖 3 个魔法强化。
- 免费提供一个随机魔法。
- 免费提供一次魔法融合。
- 魔法强化售卖价格每层提高 5 金币。
