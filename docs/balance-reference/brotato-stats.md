# Brotato 角色属性参考

来源：[Brotato Wiki - Stats](https://brotato.wiki.spellsandguns.com/Stats)

## 结构

Brotato 把属性分为 Primary Stats 和 Secondary Stats。一级属性是构筑成长的主干，决定生存、输出、移动、掉落和经济。二级属性更像玩法开关或细分加成，用于支持爆炸、穿透、弹跳、拾取范围、敌人数量、敌人速度、商店价格等特殊机制。

一级属性的核心价值是“人人可读、人人有用，但不同构筑权重不同”。例如近战伤害、远程伤害、元素伤害分别服务不同武器，通用伤害再统一放大最终输出；护甲、闪避、最大生命、生命恢复、生命偷取分别覆盖不同防御模型。

## 一级属性规律

| 属性 | 设计作用 | 数值规律 |
|-|-|-|
| Max HP | 生命池 | 不设硬上限，负值按最低生命处理 |
| HP Regeneration | 稳定恢复 | 第一点评价更高，后续点数收益较平滑 |
| Life Steal | 命中回血 | 按武器独立触发，有触发频率上限 |
| Damage | 通用增伤 | 每点约等于 1% 全局增伤，最低伤害保底为 1 |
| Melee/Ranged/Elemental Damage | 基础伤害加算 | 通过武器缩放比进入基础伤害，适合区分构筑 |
| Attack Speed | 攻击频率 | 高值存在递减或频率上限，避免无限攻速破坏表现和性能 |
| Crit Chance | 爆发概率 | 上限 100%，负值降低武器基础暴击率 |
| Engineering | 召唤物/结构强度 | 与普通输出属性隔离，避免结构流被所有通用属性重复放大 |
| Range | 武器距离 | 提升远程安全距离；对近战会影响挥动距离和冷却体感 |
| Armor | 承伤效率 | 每点提高有效生命，而不是简单线性减伤 |
| Dodge | 免伤概率 | 有明确上限，避免完全无敌 |
| Speed | 位移能力 | 可正可负，负到一定程度会让角色停滞 |
| Luck | 掉落与稀有度 | 同时影响资源、商店和升级，是经济与构筑质量属性 |
| Harvesting | 波次结算经济/经验 | 每次触发后会增长，形成早拿早收益的经济投资属性 |

## 二级属性规律

二级属性承担“规则分叉”。典型类别包括：

- 资源与经济：物品价格、重随价格、双倍材料、经验获取、拾取范围。
- 投射物机制：弹跳、穿透、穿透伤害衰减、击退。
- 伤害分支：爆炸伤害、爆炸范围、Boss/精英增伤、燃烧速度、燃烧扩散。
- 环境压力：敌人数量、敌人速度、树木数量。
- 结构支持：结构攻速、结构范围。

这些属性通常不应该出现在角色基础面板的第一屏，但应允许道具、武器羁绊、学派特性、难度词条和 buff 修改。

## 设计启发

Puritato 目前已有 `max_health`、`max_mana`、`melee_attack`、`ranged_attack`、`defense`、`attack_speed`、`health_regen`、`mana_regen` 等属性。建议保留“一级属性 + 二级属性”分层：

- 一级属性用于角色、升级、常规道具、武器/法术缩放。
- 二级属性用于学派特色、buff、稀有道具、Boss 机制和难度词条。
- 防御属性不要只用 `defense` 一把尺。建议拆出 `armor` 或保留 `defense` 但定义明确公式，再补 `dodge_chance`、`damage_reduction_percent`、`control_resistance`。
- 魔法系统需要自己的资源属性：`max_mana`、`mana_regen`、`spell_power`、`cooldown_reduction`、`mana_cost_reduction`。
- 学派机制可以用二级属性表达，例如感染强度、爆破范围、治疗效果、处决阈值、破韧效率。
