# Brotato 难度系统参考

来源：[Brotato Wiki - Danger Levels](https://brotato.wiki.spellsandguns.com/Danger_Levels)

## 结构

Brotato 的 Danger Level 是继承式难度。每一档会继承之前所有变化，再增加新的规则或数值倍率：

| Danger | 主要变化 |
|-:|-|
| 0 | 无额外修改 |
| 1 | 新敌人出现 |
| 2 | 新敌人出现，精英和兽潮出现 |
| 3 | 新敌人出现，敌人更强，生命和伤害约 +12% |
| 4 | 更多精英和兽潮，生命和伤害约 +26% |
| 5 | 最终波双 Boss，生命和伤害约 +40%，双 Boss 单体生命降低 |

这个结构的优点是每档难度都“改变体验”，而不只是增加数值。新敌人、精英密度和 Boss 数量属于规则变化，生命/伤害倍率属于数值变化。

## 辅助难度滑杆

Brotato 还有伤害、生命、速度三个辅助滑杆。修改后的难度百分比使用三者的几何平均。最低可到 25%，最高组合可达到约 182%。这些倍率与 Danger 的生命/伤害倍率相乘。

设计启发：

- 可访问性设置和正式难度应分开。正式难度用于解锁和挑战，可访问性用于玩家自调体验。
- 生命、伤害、速度分开调，比单一“难度倍率”更精细。
- 几何平均可以避免某个滑杆极端值完全支配综合显示。

## 设计启发

Puritato 建议建立两层难度：

- `danger_level`：正式挑战档，改变敌人池、精英/Boss、奖励、污染强度。
- `assist_multiplier`：可访问性倍率，只影响敌人生命、伤害、速度，默认 100%。

难度档不要一开始就做太多，Demo 可先做 0-3：

| 难度 | 名称建议 | 规则 |
|-:|-|-|
| 0 | 净土试炼 | 默认敌人池，无精英，Boss 单阶段 |
| 1 | 污染蔓延 | 新敌人提前出现，敌人数量 +10% |
| 2 | 菌潮压境 | 每章至少 1 个精英或强化小怪阶段，Boss 增加一条技能 |
| 3 | 源头暴动 | 敌人生命/伤害 +18%，Boss 二阶段，战斗奖励质量提高 |

后续再扩展到 4-5：

- 4：精英密度提高，敌人生命/伤害 +30%，特殊敌人更早出现。
- 5：终局双 Boss 或 Boss + 精英护卫，敌人生命/伤害 +45%，但 Boss 单体生命适当降低。
