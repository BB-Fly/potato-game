# Brotato 怪物属性参考

来源：[Brotato Wiki - Enemies](https://brotato.wiki.spellsandguns.com/Enemies)

## 结构

Brotato 敌人属性由生命、每波生命成长、速度、伤害、每波伤害成长、击退抗性、材料掉落、消耗品掉落、箱子掉落、首次出现波次和行为组成。敌人不是只靠数值区分，行为也非常重要：追击、逃离并射击、冲锋、加速、召唤、强化其他敌人、远程弹幕等都会形成不同压力。

玩家基础速度可作为敌人速度参照。Brotato 敌人速度范围跨度很大：低速敌人提供密度压力，高速敌人提供走位压力，远程敌人提供空间压力。

## 屏幕上限

Brotato 单波屏幕敌人上限是 100。超过上限时会随机移除非精英/Boss 敌人，且一般不掉落资源。这个规则说明敌人数量不仅是难度，也是经济来源；如果刷怪超过玩家清理能力，反而可能因为上限导致经济损失。

Puritato 当前 `max_mobs` 为 14，这是 Demo 视觉和性能友好的低密度原型值。正式平衡应把屏幕上限作为配置项，按层数、难度、设备性能和敌人体型动态调整。

## 波次节奏

Brotato 共 20 波，前期波次较短，逐步增长到 60 秒，最后 Boss 波为 90 秒。Danger 2 后出现精英或兽潮，Danger 5 最后一波双 Boss。波次系统的核心不是固定时长本身，而是“前期给构筑成型时间，中期加入精英检查，终局用 Boss 检查完整构筑”。

Puritato 是小关战斗节点，因此可以转译为：

- 第 1-2 层：短小怪阶段，验证基础操作与开局武器。
- 第 3-4 层：加入远程/冲锋/召唤敌人，验证清群与续航。
- 第 5-6 层：加入精英或 Boss 强机制，验证构筑完成度。
- 第 7 层后：进入扩展章节或高难模式，加入组合敌群。

## 敌人预算

敌人强度由五个预算决定：

| 预算 | 作用 | 典型调法 |
|-|-|-|
| 数量 | 压缩走位空间 | 提高刷怪频率或上限 |
| 生命 | 检查 DPS | 提高基础生命或层数成长 |
| 伤害 | 惩罚失误 | 提高接触/投射物伤害 |
| 速度 | 提高走位压力 | 提高移动速度或冲锋频率 |
| 行为复杂度 | 改变解法 | 远程、召唤、护盾、治疗、光环、弹幕 |

不要同时大幅提高五项。普通层主要提高数量和轻微生命；精英层提高行为复杂度；高难度再提高生命和伤害倍率。

## Boss 与精英

Brotato Boss/精英往往有 mutation 或阶段变化，按时间或血量切换行为。常见结构：

- 初始追击或随机移动，伴随基础弹幕。
- 约 70% 或 60% 生命进入第二模式。
- 约 40% 或 30% 生命进入更高压模式。
- Danger 5 双 Boss 时单体 Boss 生命会降低，但总压力显著增加。

Puritato 的污染源 Boss 已经有径向弹幕雏形，建议后续按“血量阈值 + 时间阈值”共同驱动，避免玩家 DPS 太高或太低时阶段体验失真。
