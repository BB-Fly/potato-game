# Brotato 道具数值参考

来源：[Brotato Wiki - Items](https://brotato.wiki.spellsandguns.com/Items)

## 结构

Brotato 道具是构筑差异的主要来源。道具拥有稀有度、效果、基础价格、获取上限、解锁条件和标签。当前 Wiki 记录的基础游戏加 DLC 道具数量很大，这说明道具系统承担了大量“微规则”和“构筑方向”的表达。

道具的常见设计模式：

- 纯属性道具：提高一个或多个属性，常伴随小额负面。
- 复合属性道具：给多项中等属性，并在不相关维度扣一点预算。
- 规则道具：改变商店、掉落、升级、进入商店、受击、闪避、击杀等事件。
- 召唤/周期道具：每隔一段时间生成攻击、治疗、资源或结构。
- 风险收益道具：提高输出或经济，同时提高敌人生命、数量、速度或降低生存属性。
- 构筑标签道具：通过标签让特定角色更容易抽到对应道具。

## 价格与稀有度

道具的基础价格不完全随稀有度线性增长。高阶道具通常更贵，但一些效果非常窄或带明显负面的道具可以较便宜。稀有度更像“效果复杂度和构筑影响力”的标记，而不仅是数值大小。

常见价格感：

- Tier 1：低价，通常是小属性或简单效果。
- Tier 2：中价，开始出现明显取舍和可构筑效果。
- Tier 3：较高价，常见强属性组合、周期效果或高风险收益。
- Tier 4：高价，适合独特规则、强构筑核心或稀缺机制。

## 标签池

Brotato 道具和角色都有标签。商店或箱子生成道具时，有小概率从角色标签对应的道具池中抽取，从而保证角色更容易看到契合构筑的道具。即使标签抽取没有触发，对应道具仍在普通池里，因此标签机制是“轻定向”而不是强锁定。

这对 Puritato 很有价值：当前项目已经有学派随机池和主学派保底，可以在此基础上增加更细的道具标签，例如 `poison`、`burn`、`execute`、`shield`、`economy`、`mana`、`boss_damage`。

## 数值预算规律

道具平衡的关键不是每点属性价格完全一致，而是让玩家感到取舍清晰。

建议用三类预算来评估：

| 预算 | 内容 | 说明 |
|-|-|-|
| 基础属性预算 | 生命、攻击、防御、速度、暴击、恢复 | 可用升级值作基准 |
| 规则预算 | 触发、复制、自动施放、商店变化、掉落变化 | 通常比属性更贵，需要上限或触发条件 |
| 风险预算 | 扣属性、加敌人、降经济、延迟收益 | 用于换取超额收益 |

## 设计启发

Puritato 的道具目前“土豆强化”非常直接，后续应补足道具生态：

- 每个学派至少有 8-12 个道具，其中 3-4 个是通用属性，3-4 个是学派机制，1-2 个是构筑核心。
- 普通道具应帮助玩家补短板；稀有道具应强化方向；传说道具应改变规则。
- 道具允许堆叠，但必须写清楚堆叠模型：简单加算、独立触发、概率叠加、上限叠加、只刷新持续时间。
- 高收益道具应绑定可读代价，例如生命换输出、速度换防御、敌人数量换掉落、魔法消耗换冷却。
- 道具标签不等于学派。学派决定世界观和大池，标签决定细分构筑。
