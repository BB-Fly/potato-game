# Brotato 武器数值参考

来源：[Brotato Wiki - Weapons](https://brotato.wiki.spellsandguns.com/Weapons)

## 结构

Brotato 武器分为近战和远程，最多通常持有 6 把武器。武器有 4 个品质阶级，可以由相同武器同阶合成到更高阶。每把武器由以下预算项共同决定强度：

- 基础伤害与属性缩放。
- 攻击间隔。
- DPS。
- 暴击倍率与暴击率。
- 范围。
- 击退。
- 生命偷取。
- 穿透、弹跳、爆炸等特殊规则。
- 武器职业/羁绊。
- 商店基础价格与解锁条件。

重要点：Brotato 的武器表会列出 DPS，但 DPS 不包含特殊效果和暴击，说明官方平衡时也不会把 DPS 当成唯一答案。范围、安全性、AOE、控制、资源触发和职业羁绊都占预算。

## 近战与远程差异

近战武器通常通过挥砍或突刺命中路径上的多个敌人，天然更偏清群和近身风险。远程武器发射投射物，通常单体 DPS 更高、攻击更快，但默认只命中一个敌人，需要靠穿透、弹跳或爆炸扩展清群能力。

远程投射物的距离由武器基础射程加角色 Range 共同决定。若同时拥有穿透和弹跳，通常先完成弹跳再穿透。爆炸类投射物在弹跳和穿透时都可能触发爆炸，因此这些词条的组合价值远高于单独词条。

## 品质与成长

武器 4 阶品质带来三个效果：

- 更高基础伤害或更高缩放。
- 更短或更优的攻击间隔。
- 更强特殊效果或更高触发效率。

价格也随品质上涨。部分武器有最低出现品质，适合把复杂或高爆发武器延后投放，避免开局破坏节奏。

## 职业/羁绊

Brotato 武器职业类似 Puritato 的学派或标签。多个同职业武器提供阶梯加成，通常按 2/3/4/5/6 件给奖励。例如刀刃职业偏近战和生命偷取，钝器职业偏护甲和生命但牺牲速度，元素职业加元素伤害，枪械职业加范围。

商店也会提高已拥有武器职业的出现概率。这个机制很关键：它让玩家已经做出的构筑选择反过来塑造后续随机池，同时也有代价，过多职业会稀释定向概率。

## 设计启发

Puritato 目前默认 4 个武器槽，比 Brotato 少，因此单把武器的辨识度和成长空间应更高。

建议武器设计采用“预算卡”：

| 项 | 常规范围建议 | 说明 |
|-|-:|-|
| 基础伤害 | 8-36 | 近战清群武器偏中低，重击武器偏高 |
| 缩放 | 60%-160% 主属性 | 快速武器缩放低，慢速武器缩放高 |
| 攻击间隔 | 0.35-1.8 秒 | 低于 0.35 秒要谨慎处理表现和触发频率 |
| 范围 | 80-260 | 近战 80-190，远程 180-360 |
| 暴击率 | 0%-15% | 刺杀学派可更高 |
| 暴击倍率 | 180%-250% | 高倍率要降低基础伤害或攻速 |
| 击退 | 0-30 | 控制价值应计入预算 |
| 韧性伤害 | 2-12 | 重型/战斗学派较高 |
| 特殊效果 | 0-2 个 | 常规武器 0-1，稀有/传说可 2 个 |

武器的强度不要只写成“伤害更高”。每个学派应有偏好的预算分配：

- 变形学派：均衡、属性缩放稳定、少量泛用 buff。
- 战斗学派：近战、韧性伤害、防御、击退。
- 感染学派：毒、持续伤害、传播、削弱。
- 爆破学派：爆炸范围、延迟爆发、火焰、陷阱。
- 炼药学派：治疗、护盾、正面 buff、药剂触发。
- 刺杀学派：暴击、处决、背刺/低血斩杀、移动。
- 占卜学派：幻象、概率改写、复制触发、预兆。
- 大气学派：范围、天气场、移动速度、周期环境效果。
- 自然科学学派：成长上限、跨学派缩放、工程/召唤。
