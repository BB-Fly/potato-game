# Brotato 数值参考总结

本目录记录从 Brotato Wiki 提炼出的数值设计规律。它不是对原表格的搬运，而是面向 Puritato 后续数值设计的参考笔记：关注属性结构、成长节奏、敌人压力、装备定价、升级幅度、难度调节和构筑引导。

给 Puritato 的总启发：

- 角色成长最好由少量一级属性驱动，再用二级属性承载特殊玩法。一级属性要足够通用，二级属性要足够具体。
- 武器不是单纯比 DPS，而是在伤害、攻速、范围、暴击、击退、穿透/弹跳、职业/学派羁绊、特殊效果之间做预算分配。
- 道具是构筑偏向的主要来源，高收益通常配一个可感知代价；越稀有的道具越适合提供规则变化，而不是只堆数值。
- 升级奖励提供稳定、可预期的基础属性补足，稀有度随进度和幸运类属性变化。
- 敌人压力由数量、速度、血量、伤害、行为复杂度和屏幕上限共同塑造。不要只调血量。
- 难度系统应当是叠加式规则包：先改变敌人池和精英密度，再提高数值倍率，最后改变 Boss 结构。
